# Política de revisión humana - Clínica Demo

Una receta debe pasar a revisión humana cuando el sistema detecta:

1. Información ilegible.
2. Información ambigua.
3. Campos obligatorios ausentes.
4. Contradicciones entre diferentes partes del documento.

La revisión humana debe limitarse a validar la información administrativa
necesaria para continuar el proceso.

El sistema no debe realizar decisiones clínicas.
